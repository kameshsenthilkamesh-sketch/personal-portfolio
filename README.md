# Personal Portfolio Website

A responsive personal portfolio website built using **HTML, CSS and JavaScript**. It introduces the developer, highlights skills and projects, and provides contact information.

## Features
- Responsive layout for desktop, tablet and mobile
- Home, About, Skills, Projects and Contact sections
- Mobile navigation menu
- Modern dark theme and custom visual elements
- Contact link using email
- Automatically updated footer year

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Run Locally
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Customize Before Publishing
Replace the sample details in `index.html`:
- `Your Name` with your name
- `YN` with your initials
- `your.email@example.com` with your email address
- Update the About section, skills and project descriptions to match your own work
